# Report screenshots

PNG files here were extracted from **`Adv_Blockchain_Project_Report.pdf`** (figures embedded in that document).

| Pattern | Meaning |
|---------|---------|
| `figure_01.png` … `figure_21.png` | Ordered screenshots referenced in the root **`README.md`** |
| `pdf_pageNN_imgM.png` | Original extract: PDF page `NN`, image index `M` |

To re-extract after replacing the PDF, use PyMuPDF (`pip install pymupdf`) and a short script, or export figures manually from your PDF viewer.
